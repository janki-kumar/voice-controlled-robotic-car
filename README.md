# Voice Controlled Robotic Car

A voice-controlled robotic car project developed as an embedded systems and robotics project. The system uses a robotic car chassis, DC geared motors, motor driver circuitry, a controller board, and wireless communication to control the movement of the vehicle through voice commands.

## Project Overview

The Voice Controlled Robotic Car is designed to demonstrate the basic concepts of robotics, embedded systems, motor control, and wireless communication.

Voice commands are converted into control instructions, which are then processed by the controller to operate the motors and move the robotic car in the required direction.

## Key Features

- Voice-based control
- Wireless command communication
- Four-wheel robotic car platform
- DC geared motor-based movement
- Motor driver interface
- Embedded controller-based operation
- Forward and backward movement
- Left and right movement
- Stop control

## Hardware Components

- Robotic car chassis
- DC geared motors
- Wheels
- Motor driver
- Controller board
- Wireless communication module
- Connecting wires
- Power supply/battery

## Working Principle

The basic working process of the robotic car is:

1. The user gives a voice command.
2. The voice command is converted into a control instruction.
3. The instruction is transmitted through the wireless communication interface.
4. The controller receives and processes the command.
5. The controller sends signals to the motor driver.
6. The motor driver controls the DC geared motors.
7. The motors rotate according to the command and move the robotic car.

## Control Commands

| Command | Action |
|---|---|
| Forward | Moves the car forward |
| Backward | Moves the car backward |
| Left | Turns the car left |
| Right | Turns the car right |
| Stop | Stops the car |
